**MVP Магазина приложений**



1. Эпик - Подготовка проекта и архитектуры (3ч)

&nbsp;	1.1 Задача - Создать проект, настроить зависимости (1ч)	

&nbsp;	1.2 Задача - Выбрать архитектуру, настроить базовую структуру проекта (clean 				architecture) (1ч)

&nbsp;	1.3 Задача - добавить readme (1ч)



Фича - Список приложений

2\. Эпик - Реализация списка приложений (10-12ч)

&nbsp;	2.1 Задача - Реализовать модель данных (2ч)

&nbsp;	2.2 Задача - Описать контракт репозитория и добавить usecase'ы (1ч)	

&nbsp;	2.3 Задача - Реализовать запросы к backend (2ч)

&nbsp;	2.4 Задача - Реализовать viewmodel (обработка запросов и создание state) (2ч)

&nbsp;	2.5 Задача - Добавить обработку ошибок (1ч)

&nbsp;	2.6 Задача - сверстать item приложения (2ч)

 	2.7 Задача - сверстать экран списка (1ч)

 	2.8 Задача - настроить навигацию на экран списка (1ч)



Фича - Карточка приложения

3\. Эпик - Реализация карточки приложения (7-11ч)

&nbsp;	3.1 Задача - Реализовать модель данных (2ч)

 	3.2 Задача - Добавить методы в репозиторий и добавить usecase'ы (1ч)

 	3.3 Задача - Реализовать запросы к backend (2ч)

 	3.4 Задача - Реализовать viewmodel (обработка запросов и создание state) (2ч)

 	3.5 Задача - Добавить обработку ошибок (1ч)

 	3.6 Задача - сверстать экран карточки приложения (2ч)

 	3.7 Задача - настроить навигацию на карточку приложения (1ч)



Фича - Установка/удаление приложений

4\. Эпик - Реализация установки и удаления приложений (10-15ч)

&nbsp;	4.1 Задача - спроектировать локальное хранилище (3ч)

 	4.2 Задача - Описать контракт репозитория и добавить usecase'ы (1ч)

&nbsp;	4.3 Задача - Реализовать установку приложения (3ч)

&nbsp;	4.4 Задача - Реализовать удаление приложения (3ч)

&nbsp;	4.5 Задача - Добавить обработку ошибок (2ч)

 	4.6 Задача - сверстать экран установки/удаления (или обновить карточку приложения) (2ч)

 	4.7 Задача - настроить навигацию на экран установки/удаления (если есть) (1ч)



Итого: ~ 30-41 часов 



Разброс обусловлен зависимостью от многих факторов, например:

* большая ли API, есть ли докуменация, знакомы ли мы с ней.
* насколько красивые нужны экраны.
* много ли зависимостей и нужно ли настраивать систему сборки
